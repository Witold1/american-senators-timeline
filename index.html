Use either shape. A file is one or the other. Both draw the same chart: associated people with a start and an end, each belonging to one polity such as a country or a Senate class.

These files put the month and day beside the year: startMonth, startDay, endMonth, endDay. A full date or { "year", "month", "day" } works too. Mix them freely: each start and end is read on its own. The file may be the list itself, or a list named rows, records, data, seats, or countries.
